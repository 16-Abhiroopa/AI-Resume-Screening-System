# AI Resume Screening System

## Overview
An AI-powered Resume Screening System built using Generative AI and Retrieval-Augmented Generation (RAG). The application analyzes resumes against job descriptions and provides an ATS score, skill matching, missing skills, resume summary, and interview questions.

## Features
- Upload Resume (PDF)
- Upload Job Description
- ATS Score Generation
- Skill Matching
- Missing Skills Identification
- Resume Summary
- Interview Question Generation

## Tech Stack
- Python
- Streamlit
- LangChain
- ChromaDB
- Google Gemini API
- RAG

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
streamlit run app.py
```
